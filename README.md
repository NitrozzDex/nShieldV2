## ✨ Fonctionnalités principales

* **Anti VPN/PROXY** → Bloquez les connexions suspectes
* **Anti IP Résidentiel PROXY** → Bloquez les connexions via un VPN avancé (exemple : Mysterium VPN)
* **Anti Tor, Hosting/Cloud Gaming** → Bloquez les connexions provenant de Tor, hébergeurs et services Cloud Gaming
* **Anti Réseau 4G/5G Mobile** → Stoppez les joueurs utilisant des connexions mobiles
* **Vérification du compte Discord** → Bloquez les joueurs n'ayant pas leur compte lié à FiveM
* **Filtrage par pays** → Autorisez uniquement les pays de votre choix
* **Entièrement configurable** → Webhook, activation/désactivation des protections, whitelist licence/IP, liste des pays autorisés, couleurs et messages de refus personnalisés
